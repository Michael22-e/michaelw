# Michael.W · 纯静态网址导航站

一个深色渐变风格、PC/手机自适应的个人网址导航。**纯静态页面**（HTML/CSS/JS），没有后端程序、没有数据库；站点数据存放在一个 `assets/data.js` 文件里，由本机的小工具维护。

- 前台：浏览、搜索、按分类筛选，点开新标签页跳转。
- 本地管理工具：在你自己电脑上新增 / 编辑 / 删除站点，保存后直接写回数据文件。
- 托管：可免费发布到 GitHub Pages，自动 HTTPS、全球 CDN、可被搜索引擎收录。

> 本目录 `Michael.W` 即为最终静态版工程；早期带投稿审核的动态 Flask 版本已移除，不再保留。

> **重要：如果是从 zip 压缩包取用，必须先解压成文件夹再使用。** 不要直接在压缩包里面双击 `.bat` 或 `.html`——压缩包内是临时解压运行，路径和编码会出错（报"不是内部或外部命令"、中文乱码）。
> 右键压缩包 → **全部解压 / 解压到当前文件夹** → 进入解压出来的 `Michael.W` 文件夹操作。

## 一、目录结构

```
Michael.W\
├── index.html              # 前台导航页（上线的就是它）
├── assets\
│   └── data.js             # 站点数据（唯一数据源，工具会自动改写）
├── tool\                   # 本机管理工具（不上传线上）
│   ├── 启动管理工具.bat      # 双击启动本地管理工具
│   ├── tool_server.py      # 本地小服务（标准库，无需装依赖）
│   └── admin.html          # 管理工具页面
└── backup\                 # 备份压缩包
```

## 二、本地预览

直接双击 `index.html`，浏览器即可打开首页（数据由同目录 `assets/data.js` 加载）。

如果个别浏览器对本地文件有限制，可在本目录起一个临时预览服务：

```bat
py -m http.server 5002
```

然后浏览器访问 `http://127.0.0.1:5002/`。

## 三、添加 / 编辑 / 删除网址（本地管理工具）

1. 确认已把 zip 解压成文件夹，进入解压目录的 `tool` 文件夹，双击 **`启动管理工具.bat`**；
2. 浏览器会自动打开管理页面（地址 `http://127.0.0.1:5001/`）；
3. **新增**：填名称、网址、简介、分类 → 点「保存站点」；
4. **编辑**：在列表里点「编辑」，改完「保存修改」；
5. **删除**：点「删除」并确认；
6. 保存成功后，刷新首页 `index.html` 即可看到更新。

说明：

- 网址只允许 `http://` / `https://`；填纯域名（如 `www.example.com`）会自动补成 `https://www.example.com`；
- 名称 2–50 字，简介不超过 200 字，同一网址不能重复；
- 工具只监听 `127.0.0.1`，仅本机可用；关闭黑色命令行窗口即停止；
- 工具只是帮你改写 `assets/data.js`，线上网站本身不含任何后端。

也可以不用工具，直接用文本编辑器打开 `assets/data.js`，仿照已有条目增删 `window.SITES` 里的对象：

```js
{
  "name": "站点名称",
  "url": "https://www.example.com",
  "description": "一句话简介",
  "category": "常用工具"
}
```

分类清单在同文件的 `window.CATEGORIES` 中，需要新分类先加到这里。

## 四、发布到 GitHub Pages（免费上线）

### 1. 准备仓库

1. 注册 / 登录 GitHub，新建一个 **Public** 仓库（例如名字 `michaelw`）；
2. 把本目录里的 **`index.html`** 和 **`assets` 文件夹** 上传到仓库根目录。
   - `tool` 文件夹是本机维护工具，**不需要上传**（静态托管也跑不了 Python）。

### 2. 开启 Pages

1. 仓库 → **Settings** → 左侧 **Pages**；
2. **Source** 选 `Deploy from a branch`；
3. 分支选 `main`（或 `master`），目录选 `/ (root)`，保存；
4. 等 1–3 分钟，页面顶部会给出线上地址，形如：
   `https://你的用户名.github.io/michaelw/`

### 3. 自定义域名（可选）

- 在域名服务商处把域名 CNAME 到上面的 GitHub Pages 地址；
- 仓库 Pages 设置里填入自定义域名，勾选 **Enforce HTTPS**；
- 证书由 GitHub 自动签发，无需自己配置。

### 4. 以后更新内容

1. 本地用管理工具改好站点（或手改 `assets/data.js`）；
2. 把更新后的 `assets/data.js` 重新上传到仓库；
3. GitHub Pages 自动重新发布，线上页面随即更新。

## 五、备份与迁移

- **备份**：复制整个 `Michael.W` 文件夹即可；最核心的是 `assets/data.js`。
- **换到新电脑**：拷整个文件夹 → 装好 Python（工具用，纯标准库）→ 双击 `tool/启动管理工具.bat` 继续维护；首页双击 `index.html` 即可预览。

## 六、注意事项

- 静态站是只读的，访客只能浏览，无法在线修改或投稿；内容只有你能通过本地工具改。
- 若要重新开放"访客投稿 → 后台审核"，需要回到动态方案（云服务器或动态托管），静态托管无法承担。
- 搜索引擎收录：上线后可到 GitHub Pages 地址，在百度搜索资源平台 / Google Search Console 提交网址；收录需要时间，且取决于页面内容质量。
